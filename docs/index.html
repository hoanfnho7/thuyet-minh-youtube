Key Features

Runs 100% client-side in your browser — zero data collection, no account needed.

🎙️ Natural AI Voices

Built-in free Microsoft Edge Neural voices and Google Standard TTS. Ready to use immediately without entering any API key.

⏱️ Smart Fit-to-Pacing

Dynamically adapts speaking speed to match the video speaker — from slow podcasts to fast tutorials — with automatic original audio ducking.

🎤 Bilingual Karaoke Script

Displays original and translated captions side-by-side with real-time word highlighting. Click any sentence to seek directly to that moment.

🎬 YouTube, Shorts & Ad-Aware

Auto-detects the video's native caption track, supports both standard videos and YouTube Shorts, and automatically pauses during ads.

🔑 Optional BYOK Support

Optionally connect your own OpenAI TTS (Nova) or Google Cloud WaveNet API key in the popup for premium voices.

🔒 Privacy First

Requests only local storage permission to save your settings on your device. Never logs watch history or sends personal data to any server.

Installation Guide

Compatible with Google Chrome, Microsoft Edge, Brave, and Cốc Cốc.

1

Download the extension archive

Click Download Extension (.zip) above (or visit GitHub Releases) and extract it to a permanent folder.

2

Open the Extensions page

Navigate to chrome://extensions in Chrome/Brave or edge://extensions in Microsoft Edge.

3

Enable Developer Mode & Load Unpacked

Turn on Developer mode in the top-right corner, click Load unpacked, and select the extracted folder from Step 1.

4

Start Dubbing on YouTube

Open any YouTube video with Closed Captions (CC), click the Headphone icon on the player bar (next to CC), and click Start Dubbing.

Alt + Shift + D  Toggle Dubbing
Alt + Shift + V  Toggle Bilingual Script
