# 🎧 YouTube AI Voice Dubber (Thuyết minh YouTube thời gian thực)

Tiện ích mở rộng (Chrome / Edge / Brave) giúp tự động dịch phụ đề và lồng tiếng video YouTube theo thời gian thực với giọng đọc AI tự nhiên — **miễn phí, không giới hạn thời lượng, chạy trực tiếp trên trình duyệt**.

## ✨ Tính năng nổi bật
- **Thuyết minh thời gian thực:** Hỗ trợ cả video YouTube thường và YouTube Shorts.
- **Giọng đọc AI tự nhiên:** Tích hợp sẵn giọng đọc Edge Neural (Nam Minh, Hoài My...) và Google Standard, dùng ngay không cần nhập API Key.
- **Đồng bộ nhịp thông minh (Fit-to-Pacing):** Tự động co giãn tốc độ đọc khớp với người nói (kể cả podcast nói chậm hay video review nói nhanh), tự hạ âm lượng gốc (Audio Ducking) khi thuyết minh.
- **Kịch bản song ngữ & Karaoke:** Hiển thị phụ đề gốc + bản dịch chạy sáng từng từ theo tiếng đọc, bấm vào câu bất kỳ để tua nhanh tới đoạn đó.
- **Tùy chỉnh vai xưng hô:** Tự nhận diện ngữ cảnh hoặc chọn nhanh cặp xưng hô (`Tôi - Bạn`, `Ông - Cháu`, `Anh - Em`, `Thầy - Em`...).
- **Tự động tránh quảng cáo:** Tự ngắt tiếng thuyết minh khi video chạy quảng cáo.
- **Hỗ trợ BYOK (Tùy chọn):** Cho phép nhập API Key cá nhân (OpenAI TTS / Google Cloud WaveNet) nếu muốn dùng thêm giọng cao cấp.

## 🚀 Hướng dẫn cài đặt (Thủ công)

1. Vào mục **[Releases](../../releases)** ở cột bên phải và tải file `.zip` mới nhất về máy.
2. Giải nén file `.zip` vừa tải vào một thư mục cố định (không xóa thư mục này sau khi cài).
3. Mở trình duyệt và truy cập:
   - **Chrome:** `chrome://extensions`
   - **Edge:** `edge://extensions`
   - **Brave:** `brave://extensions`
4. Bật công tắc **Developer mode (Chế độ dành cho nhà phát triển)** ở góc trên bên phải.
5. Bấm **Load unpacked (Tải tiện ích đã giải nén)** -> chọn thư mục vừa giải nén ở bước 2.

## 🎹 Phím tắt & Cách dùng
- Mở video YouTube bất kỳ có phụ đề (CC), bấm vào **icon Tai nghe** nằm ngay trên thanh công cụ trình phát (cạnh nút CC).
- `Alt + Shift + D`: Bật / Tắt nhanh thuyết minh.
- `Alt + Shift + V`: Bật / Tắt khung phụ đề song ngữ Karaoke.
